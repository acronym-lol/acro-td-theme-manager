# Theme Attributions

The themes in `themes/` are **independent color interpretations** built for
TouchDesigner using this module's own `td-base-template.css` palette system.
None of them contain source code from the projects listed below — only our own
re-implementations of publicly documented color palettes and the general design
guidelines those projects describe.

Color values (hex codes) and palettes are not themselves copyrightable, so no
license obligation attaches to these interpretations. The credits below are
provided as a courtesy to the original palette authors, and to make clear that
these themes are **not affiliated with, endorsed by, or official releases of**
any of the referenced projects. Project and product names are the trademarks of
their respective owners and are used here in a purely descriptive (nominative)
sense.

If you are an author of one of these palettes and would prefer different wording
or removal, please open an issue.

## Original / generic themes

The following themes are our own work or use generic, descriptive names and
