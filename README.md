# Acro TD Theme Manager

[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://acronym-lol.github.io/acro-td-theme-manager/)

CSS-based theme management for TouchDesigner — applies palette files to `ui.colors`, TUIK2 component params, and `op.*` shortcuts.

**Documentation:** https://acronym-lol.github.io/acro-td-theme-manager/

See [CLAUDE.md](CLAUDE.md) for full architecture, theme-file format, and customization guide.

## Installation

```bash
git subtree add --prefix=modules/acro-td-theme-manager https://github.com/acronym-lol/acro-td-theme-manager.git main --squash
```
